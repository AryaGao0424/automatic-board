## 3.1 口径体系总览

| 口径 | 定义 | 公式 / 规则 |
|---|---|---|
| 口径②"曾被退回" | 驳出共享次数 ≥ 1 | is_rejected = True |
| 退单率 | 曾被退回唯一单据 ÷ 全部唯一单据 | 465 / 7522 ≈ **6.2%** |
| 退单笔数 | 口径②下的唯一单据数 | groupby(单据编号).count() |

| 四维风险分 | 加权综合评分 | 率20% + 量20% + 额40% + 集中率20% |

## 3.2 为什么定义"口径②"？（业务理解力亮点）

**背景**：部分单据虽然最终审核通过，但中途曾被驳出共享（退回），说明**提交质量**存在问题。若只统计"最终驳回"（作业状态=审核驳回），会低估真实的退单问题。

**口径②定义**：只要"驳出共享次数 ≥ 1"，无论该单据最终是否通过，均判定为曾被退回。

**价值**：
- 反映"提交质量"而非"最终结果"，与管理动作（督办、提示函）直接对应；
- 全看板（KPI / 洞察 / 图表③ / 体检报告 / 专项分析）统一使用，保证口径一致可比。

## 3.3 退单率计算与去重规则

```
分母 = df.drop_duplicates("单据编号", keep="last")   # 全部唯一单据，保留最终状态
分子 = df[df["is_rejected"]].drop_duplicates("单据编号", keep="first")  # 曾被退回唯一单据
退单率 = 分子 / 分母 = 465 / 7522 ≈ 6.2%
```

**为什么必须去重？**
- 一张单据可能因多次驳出共享产生多条记录（驳出共享次数 = N）；
- 不去重会导致"重复退单"被重复计数，退单率虚高；
- 分子保留首次记录、分母保留最终状态，避免单号维度的信息冲突。

> 面试引申："统计一致性"是数据分析的基本功——分子分母口径对齐、去重规则明确，是一切结论可信的前提。

## 3.4 四维加权综合风险分（重点项目）

**公式**：

```
综合风险分 = 退单率得分×20% + 退单笔数得分×20% + 退单金额得分×40% + 标签集中率得分×20%
```

**各维度得分定义**（相对归一化，满分 100）：

| 维度 | 得分公式 | 表达的管理含义 |
|---|---|---|
| 退单率 | 该单位退单率 ÷ 全部单位最高退单率 × 100 | 质量：退得"不正常"的程度 |
| 退单笔数 | 该单位退单笔数 ÷ 最高退单笔数 × 100 | 体量：消耗审核人力的大小 |
| 退单金额 | 该单位退单金额 ÷ 最高退单金额 × 100（负值 clip 为 0） | 资金风险 |
| 标签集中率 | 该单位最高频退单标签占比 × 100 | 可整改性：原因越集中越易治理 |

**权重设计逻辑**（面试必讲）：
- **金额占 40% 最重**：退单背后的资金风险最大，体量大金额单位一旦退单影响更严重；
- 退单率 / 笔数 / 集中率各 20%：平衡"质量""体量"与"可整改性"；
- 权重在代码中常量化，可随内部管理标准调整。

**评级标准**：

| 综合风险分 | 评级 | 管理动作 |
|---|---|---|
| ≥ 70 | 🔴 重点关注 | 建议约谈 |
| 40 ~ 69 | 🟡 一般关注 | 需重点关注 |
| < 40 | 🟢 运行平稳 | 常规监控 |

**排序与取数**：按综合风险分降序，同分按退单笔数降序 → 取 Top 3 生成体检报告与督办令。

## 3.5 可挽回工时模型（成本换算亮点）

- **第一代**：按每笔退单经验值 0.5 小时估算（管理沟通成本）——先跑通框架；
- **升级版**：使用真实"修正作业时长"字段，审核驳回记录的实际耗时求和：

```
可挽回工时 = Σ(作业时长_秒) / 3600  （单位：小时）
智能洞察口径 = Top2 痛点单位退单数 × 平均单笔耗时
```

**价值**：把"退单"翻译成"浪费了多少小时/多少沟通成本"，让管理层直观感受问题的代价。

## 3.8 面试高频追问准备

**Q1：四维权重为什么这样定？**
→ 从管理目标出发：资金风险最大所以金额占 40%，其余各 20% 平衡质量与体量；权重常量化，可随内部标准调整。

**Q2：退单率为什么不用"最终驳回"？**
→ 口径②更贴合"提交质量"管理目标，避免低估问题（见 3.2）。

**Q3：去重后为什么同单位仍有多条？**
→ 去重是单据维度，不同单据可属于同一单位，单位维度仍是多条，两者不矛盾。

**Q4：金额表匹配不上怎么办？**
→ left join 保留主表全部单据，未匹配金额为空，图表按 0 处理并已在口径说明中注明。

**Q5：指标能不能被质疑或审计？**
→ 底部明细表保留全字段，任何指标都可下钻到单据明细，保证可追溯。
