# 📊 财务共享中心 · 应付组退单分析看板

> **概要** — 一个由实习生独立主导、从 0 到 1 完成并持续迭代 4 个版本、被部门采纳为月度 SOP 管理工具的「退单分析自动化看板」。

---

## 🎯 项目一句话定位

基于 **Streamlit + Pandas + Matplotlib** 搭建的财务共享中心应付组退单分析自动化看板：从 BIP 系统导出数据（Excel）上传即出全量分析报告，将原本**手工拉表、逐月汇总、靠经验拍脑袋**的退单管理，升级为**实时监控、自动洞察、穿透督办**的数据驱动管理模式。

---

## ✨ 核心功能模块（v4.0）

| 模块 | 功能 | 管理价值 |
|---|---|---|
| KPI 总览区 | 5 张核心指标卡片（退单笔数 / 退单率 / 整改耗时 / 最高频单位 / 最高频标签 / 最大金额单位） | 总盘子一目了然 |
| 智能业务洞察 | 自动识别 Top2 痛点单位与核心问题，动态估算**可挽回工时** | 把数据翻译成行动建议 |
| 趋势与结构分析 | 三大核心退单原因月度趋势 + 痛点帕累托结构 | 判断"顽疾"还是"偶发" |
| 各委托单位退单分析 | Top20 双图（体量排序 + 质量排序）+ **15% 管理红线** | 精准定位"谁该被约谈" |
| Top3 体检报告 | **四维加权综合风险分** + 专属痛点环形图 + 自动评级 | 一企一策、靶向治疗 |
| 穿透式督办令 | 根据 Top3 痛点动态生成可直接下发的督办指令 | 系统代替人脑写督办 |
| 多维度专项分析 | 处理人负荷 / 交易类型 / 重复退单 / 来源系统 / 制单人 Top15 | 多视角交叉诊断 |
| BIP 攻坚追踪 | 系统优化需求台账的 KPI、分类、状态筛选与高亮 | 从"发现问题"到"闭环解决" |
| 底部明细表 | 全量字段预览 + 状态高亮 + 行数滑块 | 数据可回溯可核对 |

## 🏗️ 技术架构（一句话版）

```
BIP系统导出Excel ──▶ 数据接入层(load_and_merge) ──▶ 指标计算层(KPI/去重/口径②) ──▶ 可视化展示层(Streamlit+Matplotlib)
        │                             │                              │
   主表+金额表+BIP台账          字段标准化/衍生列计算              八大模块联动渲染
```

**架构核心设计**：数据与展示分离。所有图表只认标准格式的 DataFrame，替换数据源只需改一行代码，因此可低成本复用到费用组、资产组等其他业务线。

## 🚀 快速开始

### 环境要求
- Python 3.9+（开发环境为 3.13）
- 依赖：streamlit / pandas / numpy / matplotlib / openpyxl

### 安装与启动（三分钟）

```bash
# 1. 安装依赖
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 2. 启动看板
python -m streamlit run fssc_dashboard.py

# 3. 浏览器自动打开，在左侧边栏上传 3 个数据文件即可
#    ① 主表：样例_主表_作业明细查询列表.xlsx
#    ② 金额表：样例_金额表_作业明细查询-金额.xlsx
#    ③ BIP 系统优化台账：样例_BIP系统优化点_分类汇总.xlsx（可选）
```

> 💡 一键启动方式：参照 `..\看板共享资料包\` 中的 `02-1初始化环境.bat` 与 `02-2启动看板.bat`。

### 使用样例数据
本资产包提供**脱敏样例数据**（`samples/`），可先用它体验完整功能，再替换为真实数据。
